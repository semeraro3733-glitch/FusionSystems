# Saturated fusion systems on groups of order 3^8

Work in progress: the search for saturated fusion systems F with O_3(F) = 1
and O^3(F) = F on the 1 396 077 groups of order 3^8, in the manner of
Parker-Semeraro (arXiv:2003.01600), using the FusionSystems GAP package in
`../gap/pkg/FusionSystems` (and the sglppow package for the groups).

* `report.tex`   the running report: reduction, surviving groups, tables
* `scripts/`     the GAP scripts (reduction stages, lookup tables, runs)
* `data/`        machine-readable results (survivor lists, lookup tables)
* `logs/`        logs of the runs
