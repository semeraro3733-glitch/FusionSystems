3.1-2 ProtoEssentialSubgroups
‣ ProtoEssentialSubgroups( S[, opts] )( function )

returns a record with components autreps (representatives of the Aut(S)-classes of proto-essential subgroups), sreps (representatives of their S-classes), label and path (sreps[i] is the image of autreps[label[i]] under the automorphism path[i][1] conjugated by path[i][2]). With opts := rec( exhaustive := true ) all S-centric subgroups are examined instead of Gautam's candidates.

gap> S := SylowSubgroup( PSU( 4, 3 ), 3 );;  S := Image( IsomorphismPcGroup( S ) );;
gap> r := ProtoEssentialSubgroups( S );;
gap> List( r.autreps, Size );
[ 243, 81 ]

3.1-3 ProtoEssentialAutomizerCandidates
‣ ProtoEssentialAutomizerCandidates( S, P[, opts] )( function )

the subgroups A of Aut(P) (as subgroups of the model group of FS_AutHandle( P )) containing Inn(P) with Aut_S(P) as Sylow p-subgroup and with A/Inn(P) having a strongly p-embedded subgroup, one for each Aut(P)-class. opts.candidates may be a function (S, P) returning lists of automorphisms (or model subgroups) to be used instead.

3.1-5 HasStronglyPEmbeddedSubgroup
‣ HasStronglyPEmbeddedSubgroup( G, p )( function )

whether the finite group G has a strongly p-embedded subgroup: with T a Sylow p-subgroup this is the case iff ⟨ N_G(T), N_G(Q) : Q ≤ T, |Q| = p ⟩ ne G.

3.2 All saturated fusion systems on a p-group

3.2-1 AllFusionSystems
‣ AllFusionSystems( S[, opts] )( function )

returns a list of representatives of the isomorphism classes of saturated fusion systems on the pc group S, by default those with O_p(F) = 1 and O^p(F) = F. The optional record opts may have the components OpTriv (default true), pPerfect (default true), OutFSOrders (a list of admissible orders of Out_F(S)), exhaustive (default false) and candidates (a function supplying automizer candidates, see ProtoEssentialAutomizerCandidates (3.1-3)). Progress is reported at levels 1 and 2 of InfoFusionSystems (3.2-2).

gap> L := AllFusionSystems( ExtraspecialGroup( 27, 3 ) );;
gap> Length( L );
4
gap> SortedList( List( L, OutFSOrder ) );
[ 4, 8, 8, 16 ]
gap> ForAny( L, F -> IsIsomorphicFusionSystems( F, GroupFusionSystem( PSL( 3, 3 ), 3 ) ) );
true
gap> Length( AllFusionSystems( ExtraspecialGroup( 343, 7 ) ) );
13

The last example recovers the classification of Ruiz and Viruel for 7^1+2_+ (ten systems realized by finite groups and three exotic ones).
