2 Fusion systems

2.1 Construction

2.1-1 FusionSystem
‣ FusionSystem( S, autSgens, essentials, essautos )( function )

returns the fusion system on the pc group S generated by Inn(S), the automorphisms in the list autSgens (or the group autSgens of automorphisms of S), and the automorphisms in essautos[i] of the subgroup essentials[i] of S.

gap> S := ExtraspecialGroup( 27, 3 );;
gap> E := First( MaximalSubgroups( S ), M -> IsElementaryAbelian( M ) );;
gap> A := AutomorphismGroup( E );;  n := NiceMonomorphism( A );;
gap> sl := List( GeneratorsOfGroup( DerivedSubgroup( Image( n ) ) ),
>                x -> PreImagesRepresentative( n, x ) );;
gap> F := FusionSystem( S, [], [ E ], [ sl ] );
<fusion system on a group of order 3^3 with 1 essential classes>
gap> IsSaturated( F );
false

2.1-2 GroupFusionSystem
‣ GroupFusionSystem( G, p[, opts] )( function )
‣ GroupFusionSystem( G, S[, opts] )( function )

returns the fusion system F_S(G) of the finite group G on a Sylow p-subgroup S. The underlying group of the result is the pc group Image( IsomorphismPcGroup( S ) ); the isomorphism is stored in the component F!.iso and G is the value of the attribute FusionSystemGroup. The essential subgroups are searched among the candidates of Gautam's theorem; with opts := rec( exhaustive := true ) all S-centric subgroups are examined instead.

gap> F := GroupFusionSystem( PSU( 4, 3 ), 3 );
<fusion system on a group of order 3^6 with 2 essential classes>
gap> OutFSOrder( F );  List( EssentialSubgroups( F ), Size );
4
[ 243, 81 ]
gap> List( EssentialAutomizers( F ), Size );
[ 3888, 29160 ]

2.2-3 IsFCentric
‣ IsFCentric( F, P )( operation )
‣ IsFullyNormalized( F, P )( operation )
‣ IsFullyCentralized( F, P )( operation )
‣ IsFullyAutomized( F, P )( operation )
‣ IsFRadical( F, P )( operation )
‣ IsReceptive( F, P )( operation )
‣ HasSurjectivityProperty( F, P )( operation )

the usual properties of a subgroup P of S in F: C_S(Q) ≤ Q for all F-conjugates Q of P; |N_S(P)| (resp. |C_S(P)|) is maximal in the F-class; Aut_S(P) is a Sylow p-subgroup of Aut_F(P); O_p(Aut_F(P)) = Inn(P); P is fully automized and has the surjectivity property; for all P < V ≤ N_S(P) the automorphisms of P extending to F-automorphisms of V are exactly the elements of Aut_F(P) normalizing Aut_V(P).

2.3 Saturation, O_p(F) and the focal subgroup

2.3-1 IsSaturated
‣ IsSaturated( F )( property )
‣ FS_IsSaturatedWithReason( F )( function )

whether the fusion system F is saturated; the second function returns [ true ] or [ false, reason ]. The test is the one described in Chapter 1. The essential subgroups of F are required to be F-centric and fully normalized (for the fusion system to be saturated with these essential subgroups); if this fails the result is false.

gap> F := GroupFusionSystem( PSL( 3, 3 ), 3 );;
gap> FS_IsSaturatedWithReason( F );
[ true ]
gap> S := UnderlyingGroup( F );;
gap> F1 := FusionSystem( S, [], [ EssentialSubgroups( F )[1] ], [ EssentialAutomizers( F )[1] ] );;
gap> FS_IsSaturatedWithReason( F1 );
[ false, "the surjectivity property fails at a subgroup of order 9" ]

2.3-2 OpF
‣ OpF( F )( attribute )
‣ IsOpFTrivial( F )( property )
‣ FocalSubgroup( F )( attribute )
‣ IsPPerfectFusionSystem( F )( property )

OpF( F ) is the largest subgroup of S normal in S, contained in all essential subgroups and invariant under Aut_F(S) and all Aut_F(E_i); for saturated F this is O_p(F). FocalSubgroup( F ) is ⟨ [S, Aut_F(S)], [E_i, Aut_F(E_i)] ⟩, which is the focal subgroup of a saturated fusion system; O^p(F) = F iff it is all of S.

2.4 Isomorphism

2.4-1 IsIsomorphicFusionSystems
‣ IsIsomorphicFusionSystems( F1, F2 )( operation )
‣ IsomorphismFusionSystems( F1, F2 )( operation )

whether there is an isomorphism α: S_1 -> S_2 carrying F1 onto F2, i.e. carrying the generating data of F1 into F2 and vice versa; the second function returns such an isomorphism or fail. If F1 and F2 live on the same group S, α is searched in Aut(S); otherwise an isomorphism of the groups is computed first.

gap> F1 := GroupFusionSystem( PSL( 3, 3 ), 3 );;
gap> F2 := GroupFusionSystem( MathieuGroup( 12 ), 3 );;
gap> IsIsomorphicFusionSystems( F1, F2 );
false
